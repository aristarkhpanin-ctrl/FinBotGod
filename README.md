# Исследовательская торговая система для Мосбиржи

Инфраструктура для проверки торговых гипотез на российском рынке акций
с честным учётом издержек. Полное техническое задание: [docs/TZ_trading_system.md](docs/TZ_trading_system.md).

> Главный продукт — не прибыль, а достоверный ответ на вопрос
> «работает ли эта идея после издержек». Порог безубыточности при
> капитале 20 000 ₽ — около **38% годовых**, и система показывает
> эту цифру в каждом отчёте.

### Часть II — реализовано (исследовательский контур, до боя не допущено)

| Модуль ТЗ | Где | Статус |
|---|---|---|
| Purged K-Fold + эмбарго, CSCV → PBO | `ml/validation.py` | Готово |

| Дробное дифференцирование | `features/transforms.py` | Готово |

| Модель ступени 1 + обязательный `explain`, MDA | `ml/models/`, `ml/feature_importance.py` | Готово |
| Мониторинг: CUSUM, PSI, KS-дрейф | `ml/monitoring.py` | Готово |
| Реестр моделей с проверкой хеша | `ml/registry.py` | Готово |
| Воспроизводимость по хешу прогона | `research/reproduce.py` | Готово |
| Обучение с подкреплением (ступень 4) | — | Интерфейс, в план не ставится (раздел 20) |
| LLM-признаки | `research/llm.py` | Заглушка (ретроспективная осведомлённость, раздел 21) |

Условия включения `ml.enabled: true` (ТЗ, раздел 24): инфраструктура,
тесты, журнал и дефлированный Шарп — **выполнены**; 3 месяца бумажной
торговли (фаза 8) и ≥5 лет признаков в хранилище — **нет**. Поэтому флаг
остаётся `false`: мета-модель работает только в исследовательских
скриптах, а не в торговом контуре.

## Как запустить

Нужен Python 3.11 или новее.

```bash
# 1. Установить зависимости
pip install pandas numpy httpx pydantic-settings PyYAML structlog pyarrow pytest

# 2. Прогнать тесты (сеть не нужна)
python -m pytest

# 3. Скачать данные Мосбиржи (нужен доступ к iss.moex.com)
python scripts/download_universe.py
```

Скрипт скачивает дневные свечи по 35 бумагам из `trading/config/universe.yaml`
за 2015–2026, сохраняет их в `data_cache/` (Parquet) и печатает отчёт
валидации: аномалии в данных, подозрительные скачки цены (возможные сплиты),
пропуски, лотность. **Повторный запуск не делает ни одного сетевого
запроса** — всё берётся из кэша. Обрыв сети посреди загрузки кэш не портит:
можно просто запустить скрипт ещё раз.

## Панель управления

Единственный файл, который нужно редактировать, —
[`trading/config/settings.yaml`](trading/config/settings.yaml).
Каждый параметр подписан по-русски с единицами измерения. Ошибка в
конфиге приводит к отказу запуска с объяснением, а не к падению.

Стресс-тест издержек: поставить `стресс_множитель: 2.0` — все издержки
удвоятся. Стратегия, умирающая при удвоении издержек, не имеет запаса
прочности.

## Результаты исследований (все — out-of-sample, после издержек)

Ни одна проверенная идея не прошла порог безубыточности ~38% годовых;
все проигрывают фонду денежного рынка под 14,25%. Подробности — в `docs/`.

| Идея | Таймфрейм | OOS-доходность | Отчёт |
|---|---|---|---|
| Моментум | день | +3,0% | `research_2026-07.md` |
| Моментум с фильтром | день | +5,6% | `research_2026-07.md` |
| Возврат к среднему | день | +3,5% | `research_2026-07.md` |
| Шорт: моментум вниз | день | −6,0% | `research_short_2026-07.md` |
| Шорт: откат перегретых | день | −8,3% | `research_short_2026-07.md` |
| Моментум | неделя | −1,5% | `research_timeframes.md` |
| Моментум | месяц | +7,9% | `research_timeframes.md` |
| Моментум | квартал | +6,2% | `research_timeframes.md` |
| USD/RUB → экспортёры | день | +1,3% | `research_cross_asset.md` |
| Мета-разметка (ML, Часть II) | день | +1,5% | `research_meta_labeling.md` |
| Внутридневная | минуты | не строится (издержки, ТЗ) | `intraday_analysis.md` |

На Мосбирже вывод устойчив ко всем срезам: простые ценовые правила не
окупают инфраструктуру при ключевой ставке 14,25% (порог ~38%). Мета-фильтр
(ML) снизил просадку, но не прошёл дефлированный Шарп и PBO.

|---|---|---|---|---|
| Крипта, моментум | +59% годовых | ~4,5% | «проходит», но −74% просадка | `research_crypto.md` |

| Крипта, купил-и-держи BTC | +54,8% | — | (бенчмарк) | `research_crypto.md` |

Крипта — единственный рынок, где критерий остановки не сработал. Но это
следствие низкого порога (4,5% против 38%) и исторических бычьих рынков:
6 из 10 окон убыточны, просадки 67–74%, результат едва обгоняет удержание
BTC и сильно завышен выживаемостью выборки. **Выбор рынка повлиял на
вердикт сильнее любой изощрённости стратегии.**

## Что уже защищает от самообмана

- **Модель издержек в ядре**: комиссии, спред, проскальзывание, растущее
  с размером заявки; заявка больше 5% дневного оборота отклоняется как
  нереализуемая (`trading/core/costs.py`).
- **Журнал гипотез**: каждый прогон записывается с хешем конфигурации и
  данных; отключить нельзя, удалить запись нельзя; сводка показывает
  медиану по всем конфигурациям, а не только лучшую
  (`trading/research/ledger.py`).
- **Реестр признаков**: признак без явно указанной задержки доступности
  данных (`availability_lag`) не регистрируется — защита от утечки
  будущего (`trading/features/registry.py`).
- **Валидация данных**: дубликаты, битые свечи, пропуски, детектор
  сплитов — всё в отчёте, ничего молча (`trading/data/validation.py`).
- **Дисциплина времени**: стратегия получает срез данных по день T,
  исполнение — по цене открытия дня T+1; тест со сдвигом сигнала
  подтверждает отсутствие утечки будущего (`trading/engine/backtest.py`).
- **Сайзинг по лотам**: floor по лотам, пропуски с причиной по-русски,
  отчёт о разрешающей способности капитала до кривой доходности
  (`trading/core/sizing.py`).
- **Три бенчмарка в каждом отчёте**: стратегия / индекс IMOEX / фонд
  денежного рынка под 14,25%; проигрыш безрисковой ставке печатается
  первым и крупно (`trading/reporting/report.py`).
- **Walk-forward**: параметры подбираются только на обучающем окне,
  метрики — только по склейке проверочных; больше 3 параметров — ошибка;
  в отчёте медиана по всем конфигурациям и вердикт по критерию остановки
  проекта (`trading/research/walkforward.py`).
- **Риск-слой**: 7 предохранителей, не зависящих от стратегии, — от
  обрезания заявки до полной остановки системы; дневной лимит убытка
  и просадка от пика меряются по фактической стоимости портфеля;
  сработавшие предохранители всегда в отчёте (`trading/risk/guards.py`).

## Структура

```
trading/
├── config/         настройки (панель управления) и белый список бумаг
├── data/           клиент MOEX ISS, кэш Parquet, валидация, универсум
├── core/           модель издержек, сайзинг, портфель — готово
├── research/       журнал гипотез, walk-forward (готово); LLM (Часть II)
├── features/       реестр признаков (готово); хранилище (Часть II)
├── ml/             Часть II, выключено фича-флагом
├── strategy/       интерфейс стратегии + референсный «купил и держи»
├── risk/           независимый риск-слой, 7 предохранителей — готово
├── engine/         backtest (готово) / paper (фаза 8) / live (фаза 9)
├── execution/      симулятор исполнения (готово); ALOR (фаза 9)
└── reporting/      метрики, отчёты, журнал решений, месячный CSV — готово
scripts/            download_universe.py — загрузка данных с отчётом
tests/              143 теста, работают без сети
```
